# obihod-tg-relay

Ретранслятор уведомлений о заявках obikhod.ru в Telegram (бот @OBIHODLEADBOT).

С VPS в РФ `api.telegram.org` недоступен. Сайт кладёт сообщение файлом в очередь, сервер коммитит его
в `queue/` этого репозитория (deploy key с правом записи только сюда), workflow `Telegram` отправляет
его в чат. Секреты: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, `RELAY_KEY`.

С 28.10.2026 в сообщении имя и телефон клиента (решение владельца; трансграничная передача описана в
политике и согласии на сайте). Поэтому файлы в `queue/` зашифрованы (`*.json.enc`, AES-256-CBC + PBKDF2,
ключ — `RELAY_KEY`, его копия только на сервере) и расшифровываются в workflow перед отправкой.
Почта, адрес, описание задачи и фото в сообщение не попадают. Исходники — `deploy/telegram/` в репо сайта.
