# Миграции до 20.10.2026

- `history/` — миграции времён dev-push (апрель–октябрь 2026). Были диффами поверх схемы,
  созданной push-ем, поэтому с пустой БД не проигрываются. **Не запускаются** (Payload читает
  только файлы верхнего уровня `migrations/`), лежат как история.
- `sync-to-baseline.sql` — разовая синхронизация «старой» БД (прод, staging, старая локальная)
  со схемой базовой миграции `20261020_120000_baseline`. Применяет `scripts/migrate.ts` сам,
  один раз, в транзакции вместе с отметкой базовой миграции (план 09, этап 1 — «Дрейф схемы»).
